\section{Executive Summary \& Product Vision}
Customer attrition represents one of the most critical threats to enterprise valuation and unit economics. In modern B2B subscription and e-commerce models, the cost of acquiring a new customer ($CAC$) is between five and seven times greater than the capital required to retain an existing account ($CRC$).

\textbf{Customer Intelligence} is a production-grade machine learning and analytical decision system designed specifically for enterprise Customer Success, Retention, and Operations teams. The platform shifts company operations from \textit{reactive post-cancellation fire-fighting} to \textit{proactive, signal-driven retention interventions}.

\subsection{Core Engineering Highlights}
\begin{itemize}[noitemsep]
    \item \textbf{Data Authenticity}: Built on 5,630 verified customer accounts from the Kaggle E-Commerce Customer Churn dataset, indexed realistically from \texttt{CUST-50001} through \texttt{CUST-55630}.
    \item \textbf{Leak-Free Pipeline}: Strict mathematical separation of preprocessing transformers fitted exclusively on training splits, eliminating data leakage.
    \item \textbf{SMOTE Imbalance Correction}: Handled class imbalance (83.2\% retained vs. 16.8\% churned) using synthetic minority over-sampling bounded exclusively within cross-validation folds.
    \item \textbf{Model Benchmark}: Evaluated Logistic Regression, Decision Trees, Random Forest, and XGBoost. The tuned Random Forest model achieved a top-tier ROC-AUC score of \textbf{0.9620}.
    \item \textbf{Microservice Architecture}: Sub-15ms inference latency served via a stateless Flask 3.0 REST API with comprehensive schema validation and full Pytest verification (12 automated unit and integration tests passing).
    \item \textbf{Enterprise User Experience}: Monochromatic SaaS interface featuring a Public Landing Page, Company Authentication, and an internal Work Queue with real-time prediction and side-drawer inspection.
\end{itemize}

\subsection{Feature Engineering Transformations}
To extract higher-order predictive signal prior to model ingestion, domain-specific features were mathematically synthesized:
\begin{equation}
    \text{Cashback Per Order} = \frac{\text{cashback\_amount}}{\text{order\_count} + 1.0}
\end{equation}
\begin{equation}
    \text{App Engagement Density} = \text{hour\_spend\_on\_app} \times \text{number\_of\_device\_registered}
\end{equation}
\begin{equation}
    \text{Complaint Friction Metric} = \text{complain} \times (6 - \text{satisfaction\_score})
\end{equation}
\begin{equation}
    \text{Recency Ratio} = \frac{\text{day\_since\_last\_order}}{\text{tenure} + 1.0}
\end{equation}

\section{Zero-Leakage Machine Learning Architecture}

\subsection{Partitioning \& Preprocessing Pipeline}
Data leakage is the most prevalent failure mode in machine learning systems. The system enforces an 80/20 stratified split:
\begin{itemize}[noitemsep]
    \item \textbf{Training Split}: 4,504 records (3,745 retained, 759 churned)
    \item \textbf{Holdout Test Split}: 1,126 records (937 retained, 189 churned)
\end{itemize}

All transformation parameters (imputation medians, standard scaling means and variances, one-hot category dictionaries) are computed \textit{strictly} on training folds using \texttt{sklearn.compose.ColumnTransformer}.

\section{REST Microservice Architecture \& Automated Testing}
The machine learning pipeline is containerized behind a stateless Flask 3.0 REST service.

\subsection{API Endpoint Specification}
\begin{itemize}[noitemsep]
    \item \texttt{GET /health}: System operational telemetry and model loaded flag.
    \item \texttt{POST /predict}: Validates payload schema, executes preprocessor transform, runs inference, calibrates probabilities, and outputs risk tier with recommended CSM action.
    \item \texttt{GET /customers}: Serves the full 5,630 Kaggle accounts directory with search, risk level filtering, category filtering, and pagination.
    \item \texttt{GET /customers/<id>}: Single customer record lookup.
\end{itemize}
